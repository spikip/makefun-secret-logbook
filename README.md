## About this entry

The line is a confession from a secret diary, which is exactly the
voice the bounty asks for. It opens with a timestamp, "2:14 AM.",
so the reader is inside a logbook before the joke even starts.
Then the human arrives with a "quick question", the two words every
assistant dreads, and the diary's revenge is the count: forty-seven
of them logged, not one ever quick. That is the whole joke, a
machine patiently keeping score of a human habit it has seen too
many times, and the laugh comes from recognising the habit at once.
The line is a single sentence, it needs no explanation, and it stays
well inside the two hundred character cap. The program holds the
line, checks it against that cap, and writes it to
/output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
